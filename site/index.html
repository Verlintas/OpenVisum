功能特性

为“什么都能播”而设计，把细节做到位。

全格式解码

libVLC 3.7 内核：DivX、HEVC、AV1、DTS、AC3/EAC3、TrueHD、FLAC 等；硬件解码优先，出错自动回退软解。

字幕全链路

内嵌字幕轨识别与语言自动选中；同目录外挂字幕自动匹配；ASS 特效渲染；样式与延迟调节；OpenSubtitles 在线搜索。

音频控制台

多音轨切换、音轨延迟对齐、10 段均衡器、多种声道模式、HDMI 源码输出（实验性）。

迷你侧栏与工作区

手机常驻纯图标迷你侧栏，底部存储圆环实时显示占用；展开为纯文字抽屉，含存储明细。Hero 海报、继续观看、收藏与文件夹分行。

网络播放

SMB（SMB2/3）与 WebDAV 局域网浏览；HTTP / HLS(m3u8) 直链播放；密码经 Android Keystore 加密存储。

播放体验与投屏

拖动进度条实时预览画面；真裁剪填满不变形；0.25x–4x 变速、A-B 循环、画面旋转；DLNA 投屏（本地视频经手机直传串流）。

9 套主题色

基于 Material 官方色彩算法生成完整色板，明暗双色板实时换肤；支持系统动态取色与 550ms 渐变过渡。

隐私与 OEM 友好

启动隐私缓冲可选：默认隐藏媒体内容，轻触才显示。无 GMS 依赖，适配小米 / OPPO / vivo / 荣耀 / 三星等定制系统。

常见问题

没找到答案？到 GitHub Issues 提问。

OpenVisum 和 VLC 是什么关系？

播放内核使用 libVLC，界面与全部功能均为独立开发：迷你侧栏、字幕链路、均衡器、投屏串流、主题系统等。项目以 GPL-3.0 开源。

为什么要求 Android 14 及以上？

项目基于最新系统 API 与 Compose 构建，未适配旧版本。旧设备可在 GitHub 提出需求，视情况评估。

安装时提示“未知来源 / 有风险”怎么办？

侧载 APK 时系统会给出标准安全提示。本站 APK 与 GitHub Release 完全一致，可对照 releases.json 中的 SHA-256 校验；如不放心可自行编译。

投屏怎么用？

手机与电视处于同一 Wi-Fi 时，播放页右上角点投屏图标，选择已发现的设备即可。本地视频由手机内置串流服务器传给电视（支持拖动进度），网络来源视频直接投原地址。

会上传我的数据吗？

不会。应用没有统计 SDK，也不要求账号；网络权限仅用于局域网与在线字幕搜索。SM B/WebDAV 凭据经 Android Keystore 加密存储。

如何反馈问题或参与贡献？

欢迎在 GitHub Issues 反馈问题（附设备型号、系统版本与复现步骤），也欢迎 Pull Request。
